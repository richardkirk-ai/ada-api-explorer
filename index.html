Drop-in — Front-end SDK

Add embed2.js, call adaEmbed.start() and setMetaFields(…). Ada renders and runs the whole chat UI, client-side, in minutes. Subscribe to ada:* events to react.

Build-your-own — Conversations API

Create a channel, POST messages from your server, receive replies by webhook. You own the UI and the surface — Ada is the engine. Exactly the flow animated above.

Design the chat, not just the answers

The Front-end SDK and Conversations API let you render the AI agent any way you like — a frosted overlay, an inline carousel, a voice orb, a proactive nudge — over whatever your app already shows. Same engine, knowledge and actions behind every surface; the design is entirely yours. Eight illustrative concepts across industries.
